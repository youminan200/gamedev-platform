# Antigravity Rules: DevGround Cross-Platform Hub

## Targets & Tools
- Mobile Frontend: Cross-Platform (iOS Safe Area & Android Material design)
- Backend & Deploy: VS Code + Node.js (TypeScript) REST API
- IDEs: Android Studio (Build/Emulation), VS Code (Core Development), Antigravity (AI Orchestration)

## Conventions
- Commits: Conventional Commits (feat, fix, docs, refactor, chore)
- Secrets: Never include real keys or passwords in repo (.env is ignored)
